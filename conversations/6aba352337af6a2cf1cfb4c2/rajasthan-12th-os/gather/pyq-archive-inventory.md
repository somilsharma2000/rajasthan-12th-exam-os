## 5. HONEST ASSESSMENT

### Can we fetch and parse PDFs programmatically, or does the founder need to upload clean PDFs?

1. **Web Fetching & Accessibility Bottleneck:**
   - **Official Government Domains (`rssb.rajasthan.gov.in` / `rsmssb.rajasthan.gov.in`):** Direct curl/Python connections from standard cloud environments fail due to OpenSSL legacy renegotiation blocking (`UNSAFE_LEGACY_RENEGOTIATION_DISABLED`) and IP-based geofencing/firewall timeouts. Automated scraping of official RSSB PDF endpoints requires an Indian residential proxy or browser automation with OpenSSL legacy ciphers enabled.
   - **Coaching Aggregators (Testbook, Utkarsh, etc.):** While archive landing pages return HTTP 200 OK and render clean Devnagari question text in web/JSON formats, direct PDF download buttons trigger client-side JavaScript authentication modals or mobile app deep-links.

2. **Parsing & OCR Quality Bottleneck:**
   - **Founder-Uploaded PDFs in Workspace (e.g. Jail Prahari CEN 17/2024, LDC 2024):** These files are rasterized image scans. Standard PDF extraction libraries (`pdfplumber`, `pdftotext`, `PyPDF2`) produce garbled or empty output on Devnagari script due to missing font maps and unaligned baseline bounding boxes.
   - **Clean Vector PDFs vs Scanned PDFs:** For programmatic PDF parsing without OCR errors, the input PDF must be a native vector PDF (where Hindi text is selectable). If vector PDFs are used, `pdfplumber` / PyPDF2 extracts Hindi UTF-8 text cleanly.
   - **If Scanned PDFs are used:** Requires a dedicated Hindi OCR pipeline (e.g., Tesseract OCR with `hin` traineddata + image binarization and deskewing).

3. **Actionable Recommendations:**
   - **Short-term Solution:** Ingest the clean web-rendered text directly from verified HTML/JSON test archives (e.g. Testbook / Shikshanagari / Scribd text streams), which store questions in clean Devnagari UTF-8 strings.
   - **Long-term PDF Pipeline:** The founder should upload clean, original vector PDFs directly downloaded from RSSB (or a local script using an India residential IP can download the original vector PDFs). This eliminates OCR corruption completely.
